# Three-minute presentation walkthrough

**Before you start:** run `npm run dev`, open the address, click **Presenter mode**. All three missions are ready and *none* is pre-completed. Press **Esc → Resume** any time. The in-game *Presenter tools* panel (top/side) has the jump buttons and run sheet.

| Time | Say | Do |
|---|---|---|
| 0:00 | "This is a **proposed future** — Singapore 2040. It's a speculative design, not an existing programme. Everyone here is fictional. The question: *who decides how a neighbourhood memory is kept?*" | On the void deck, point at Aisha, the empty memory board and the kiosk. |
| 0:25 | "A photo alone isn't a record. Here two people remember the same dinner differently." | Jump → **Mission 1**. Examine the photo (note what it *can't* tell you). Talk to Uncle Lim and Mei. Press **J**: attach two verified details (try the unverified one — it's refused), **Keep both recollections**, choose the sharing both agreed to, Save. |
| 1:10 | "Memory is often disputed. We keep both, and we don't invent a date." | Jump → **Mission 2**. Hear Madam Devi and Mr Rahman. Ask each about their name (Mr Rahman prefers "a neighbour"). In the journal: keep both perspectives, **mark the date uncertain**, add context notes, Save. |
| 1:50 | "Some memories are not for everyone. The system should respect that." | Jump → **Mission 3**. Choose **Public** on purpose — Auntie Salmah gently explains. Choose **Selected family members**. |
| 2:20 | "Contributors can add their own stories. Everything here is a simulation." | Jump → **Kiosk and board**. Show the demo-only label. Add a sample memory as *Public*; point at the board — it appears. Add one *Family-only*; show it is *not* on the board but is in the **Restricted records (demo)** tab. |
| 2:45 | "A neighbourhood's history is made of ordinary lives. What story would you help keep?" | Talk to Aisha → **See what we kept**. End on the quote. |

**If you're short on time:** in *Presenter tools* use **Stage as demo shortcut** for a skipped mission. It will be labelled "staged for demo (not completed by player)" in the HUD, journal and summary — say so to the audience.

**Reset between runs:** *Presenter tools → Reset all missions* (or Pause → Reset demo). Normal play progress is stored separately and is not touched.

**If something goes wrong:** Pause → "I'm stuck", or reload; presenter progress persists in the browser.

**Honest points to make in Q&A**
- The "restricted records" list is a simulation on one device, not real access control.
- No real data, uploads or network; all art is generated in code.
